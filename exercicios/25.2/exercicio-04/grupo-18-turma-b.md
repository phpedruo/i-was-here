## Visão Geral do Projeto
Este projeto visa o aprendizado e presenciar situações reais ao colaborar com projetos com git e github

## Público-Alvo
O projeto é destinado a usuários que precisam organizar atividades em grupo, como estudantes, equipes pequenas, freelancers e grupos informais que desejam manter controle eficiente de suas responsabilidades.

## Funcionalidades Principais
- Cadastro e gerenciamento de tarefas com prazos definidos  
- Sistema de comentários e comunicação dentro de cada tarefa
